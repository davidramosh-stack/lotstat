Configuración

Conecta LotStat a tu Google Sheet

1. Crear el Apps Script (backend)

El archivo Code.gs es el motor que conecta la app con tu Google Sheet. Solo necesitas pegarlo una vez.

  1. Abre script.google.com con tu cuenta Google
  2. Crea un Nuevo proyecto vacío y elimina todo el código
  3. Pega el contenido completo del archivo Code.gs generado
  4. Guarda el proyecto (Ctrl+S)

2. Publicar como API Web

  1. Haz clic en Implementar → Nueva implementación
  2. Tipo: Aplicación web
  3. Ejecutar como: Yo · Acceso: Cualquier persona
  4. Haz clic en Implementar y autoriza los permisos
  5. Copia la URL que aparece y pégala abajo
⚠ Si modificas Code.gs luego, necesitarás hacer una nueva implementación.

3. Inicializar hojas

Esto crea las hojas Resultados, Loterias y Patrones con toda la data histórica ya cargada.
